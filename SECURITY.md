# Security

## Report a vulnerability

Please report security issues through [GitHub private vulnerability reporting](https://github.com/Saturation-IO/n8n-nodes-saturation/security/advisories/new).

Include the affected version, the conditions required to reproduce the issue, and its likely impact. Do not open a public issue for an unpatched vulnerability.

Saturation will acknowledge the report and coordinate disclosure through the private advisory.

## Supported versions

Security fixes are released on the latest npm version. Update to the current version before reporting an issue that may already be fixed.
